Code for EspressoBot, which competed at the McMaster University 2024 Robot Sumo Competition.

▶️ [Best Moments Video](https://www.youtube.com/watch?v=dHQ6fCmV7Aw)

- Modeled, assembled, and coded the robot that won 1ST PLACE out of 32 teams at the annual McMaster University Mini Robot Sumo Competition in January 2024.
- Implemented sliding-window moving average using a circular buffer to perform O(1) incremental updates for IR sensor smoothing and noise rejection
- 1st place out of 32 teams.
